# rdc-exporter Agent Instructions

## Repository entry guide

Before making code changes, read the repository root [`agent.md`](agent.md) and
follow its document-reading workflow. Read every architecture, glossary,
contract, data-model, or coding-style document that `agent.md` requires for the
current scope before editing.

`agent.md` and the project documents it names are the sources of truth for
development rules. If `agent.md` is missing, stop and report that the repository
entry guide is unavailable.

## Project plans

When creating or updating an implementation plan for this repository:

- Store the project-level Markdown manuscript under `docs/plans/manuscripts/`;
  do not leave it only in user-level plan storage.
- Name new manuscripts `YYYYMMDD-<short-topic>.md`.
- Create or update the relevant manuscript before implementation.
- Update an existing manuscript for the same topic instead of creating a
  duplicate.
